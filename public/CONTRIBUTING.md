# Como dar sugestões

Obrigado por querer ajudar o projeto Filhos de Maria!

## O que você pode fazer
- Abrir uma **Issue** (aba "Issues") para sugerir melhorias, apontar erros de
  texto ou avisar sobre algo que não funciona.
- Usar a aba **Discussions** para ideias e dúvidas.

## O que não é aceito
- Alterações diretas no projeto. Somente os responsáveis aprovam e publicam
  mudanças. Pull requests só serão analisados se forem solicitados.

## Conteúdo religioso
Textos de orações e meditações são conferidos antes de qualquer mudança.
Sempre que possível, indique a fonte da sua sugestão.

Veja também o arquivo LICENSE.
